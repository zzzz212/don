# DaData интеграция для ЮрИИст

## Что это даёт?

DaData API предоставляет надёжные и актуальные данные о компаниях из ЕГРЮЛ, судебных реестров и других источников. Это замена местами нестабильным API ЕГРЮЛ и позволяет:

- ✅ Получить информацию о компании по ИНН (название, адрес, статус, данные о руководителе)
- ✅ Проверить статус регистрации и ликвидации
- ✅ Интегрировать судебные данные и информацию о задолженностях
- ✅ Быстрая и надёжная интеграция (99.9% uptime)

## Установка

### 1. Создать аккаунт DaData

1. Перейдите на https://dadata.ru
2. Зарегистрируйтесь (бесплатно)
3. Подтвердите email
4. В личном кабинете найдите "API и интеграции"

### 2. Получить ключи

В разделе "API ключи":
- **API Token** — скопируйте в `DADATA_API_KEY`
- **Секретный ключ** — скопируйте в `DADATA_SECRET_KEY`

### 3. Добавить переменные в `.env`

```bash
# .env (dev)
DADATA_API_KEY=your-api-key-here
DADATA_SECRET_KEY=your-secret-key-here

# .env.production (prod)
# То же самое, но с prod ключами
```

### 4. Протестировать

```bash
# Запустите эндпоинт проверки контрагентов
curl -X POST http://localhost:3000/api/counterparty/check \
  -H "Content-Type: application/json" \
  -d '{"inn":"7708119296"}'
```

## Стоимость

**DaData бесплатный для первых 100 запросов в месяц**, потом:
- Запросы к company suggest: ₽0.50 за запрос (500 запросов = ₽250)
- Запросы к party clean: ₽1.00 за запрос
- Судебные данные: дополнительный платный тариф

**Для небольшого бизнеса**: 100 запросов в месяц бесплатно = вполне хватает

## Как это работает в коде?

### Приоритет источников данных

```typescript
// src/lib/counterparty.ts
1. DaData API ← основной, самый надёжный
2. ЕГРЮЛ API ← fallback при ошибке DaData
3. Mock data ← для локальной разработки без интернета
```

### Использование в коде

```typescript
// Автоматически использует DaData если ключи есть
const profile = await fetchFromEgrul("7708119296");

// Прямой запрос к DaData
import { fetchFromDaData } from "@/lib/dadata";
const data = await fetchFromDaData("7708119296");
```

## Удаление DaData (откат)

Если понадобится вернуться к ЕГРЮЛ только:

1. Удалить переменные из `.env`
2. Закомментировать строку в `src/lib/counterparty.ts`:
   ```typescript
   // const daDataResult = await fetchFromDaData(inn);
   ```
3. Система автоматически упадёт на ЕГРЮЛ fallback

## FAQ

**Q: Что если DaData недоступен?**
A: Автоматический fallback на ЕГРЮЛ API, потом на mock-данные.

**Q: Безопасно ли отправлять ИНН на внешний сервис?**
A: Да, ИНН — это публичные данные. DaData использует шифрование TLS, как и ЕГРЮЛ.

**Q: Можно ли использовать одного пользователя на несколько приложений?**
A: Да, один API ключ можно использовать на все приложения.

**Q: Какова задержка API?**
A: 100-500 мс обычно, 1-2 сек максимум. Мы установили timeout 8 секунд.
